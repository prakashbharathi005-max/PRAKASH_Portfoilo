RTL / FPGA / Embedded

NeuroFlex — EMG-Based Wearable Hand Exoskeleton

Intelligent Rehab & Assistive Motion System

  • EMG sensor module acquires forearm bioelectric signals (~0.1–5 mV, 20–500 Hz); conditioned to 0–3.3V analog output via instrumentation amp, band-pass filter, and envelope detector. ESP32 performs 12-bit ADC sampling at ~1 kHz and transmits packetized samples over UART at 115200 baud.
  • Cyclone III FPGA is the main processing unit — all real-time signal processing implemented in Verilog/RTL: UART receiver, EMG sample buffer (shift register), digital moving-average filter, hysteresis threshold detector, peak detector with debounce, and Gesture Recognition FSM.
  • FPGA-generated PWM (50 Hz, 1–2 ms pulse) drives servo motors; nylon tendon routing converts servo rotation into finger flexion/extension for assisted hand movement. MATLAB used for offline waveform visualization (non-critical path).
